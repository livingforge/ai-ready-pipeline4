**どうするかはメッセージ本文に書いてある。**検出は `[error] G013 …/受注.yml:47 s1-t1:
参照だけのレコードしかありません（いちばん詳しい 1 シートで type / name / statement を
書いてください）` の形で出る。`ファイル:行` がそのまま開ける場所で、後半が次にやること
である。この文書が持つのは、メッセージだけでは決まらないものだけである。

| 系 | 意味 | 正本 |
| --- | --- | --- |
| `P0xx` | パース（読めない形式・壊れたファイル） | [parse.md](parse.md) |
| `G0xx` | 整理結果と凍結ゲート | [organize.md](organize.md)（書き方）／[freeze.md](freeze.md)（ゲート） |
| `B0xx` | 機械構築（マージ・関係・台帳） | [build.md](build.md) |

| `M0xx` / `C0xx` / `I0xx` | メタモデル / パック準拠 / 置き場 | ― |

**`P0xx` と `P1xx` は別物である。**`P0xx` は資料を読めたか、`P1xx` は設計書が読める
ものになっているかを見る。

## 指摘は段階的に開く（`check` / `lint` / `conform`）

**一覧は省略してある。**数百件をそのまま並べると、同じ文の繰り返しで文脈が埋まる。

| 段階 | 打つもの | 出るもの |
| --- | --- | --- |
| ① 全体像 | `arp4 check --summary` | `code` ごとの件数と本文 1 つずつ（十数行） |
| ② 1 種類を開く | `arp4 check --code W043` | その系だけを切らずに全部（`--code W0` で系ごと） |
| ③ 全件 | `.arp/out/findings.json` を読む | 毎回書かれる。UTF-8・省略なし |

既定は①と②の中間で、`code` ごとに先頭 5 件までである。**error は切らない。**件数と終了
コードは `--code` の絞り込みに影響しないので、絞って error が消えても終了コードは変わらない。

**文章を正規表現で割らない**（書式は約束していない）。

## 資料が読めない（`arp4 parse`）

**次にやることは `P001` / `P010` のメッセージ本文にある**（拡張子と先頭バイトから判った
実体で言い分ける）。残りの資料は落ちていない。1 冊が開けなくてもパースは続く。

arp4 の外でやることになるものだけ挙げる。

| よくある形 | 次にやること |
| --- | --- |
| `.xls` / `.xlsb` | Excel で開いて `.xlsx` として保存し直す |
| `.doc` / `.ppt` | Word / PowerPoint で開いて `.docx` / `.pptx` として保存し直す |
| `.zip` / `.7z` / `.lzh` | 展開してから渡す。中の資料はまだ 1 冊も読んでいない |
| OLE 複合ドキュメント | パスワード保護か旧 `.xls`。保護を外して `.xlsx` へ |
| PDF にパスワードが掛かっている | 保護を外したものをもらい直す。資料は壊れていない |
| 拡張子だけが違う（中身は PDF） | 名前を `.pdf` に直して渡し直す。**そのまま読める** |
| 開く権限がありません | 資料は壊れていない。開いたままのプログラムを閉じる |
| Python として構文が通りません | Python 2 のコード。原本はテキストのまま読める |
| UTF-8 でも cp932 でも読めません | EUC-JP・UTF-16 のソース。UTF-8 で保存し直す |

`arp4 render` が「Excel を起動できませんでした」と出すときは、その環境に Windows と
Microsoft Excel が無い。**代わりは無いので、あなたには直せない** → [parse.md](parse.md)。

`P016`（貼り付け画像の中の文字を読めませんでした）も同じ形である ―― Windows OCR が
無い環境（Windows でない・言語パックが入っていない）で出る。**資料は落ちていない**：
画像の実体は出ているので、あなたが開けば読める。ただし平坦な画像（表・画面・帳票を
撮ったもの）まで 1 枚ずつ開くことになるので、読む量は増える → [parse.md](parse.md)。

### `G004` は 2 つの形で出る

**「同じ塊が `s6-t1` にあります」と出ていたら、綴り違いではない。**アンカーの `s` は
ブックの中でシートが何枚目かを表すので、資料が改訂されてシートが 1 枚差し込まれると、
それより後ろがまとめてずれる。整理結果を書き直す前に、資料が入れ替わっていないかを
先に確かめる。

**`G004 対応するパース結果がありません`（ファイル単位）は別のことを言っている。**
整理結果はあるのに、相方のパース結果が無い（名前は拡張子を除いて 1:1）。中身が 1 件も
正本に入らないうえ、`out_of_scope` だけのファイルはこの形でしか出ないので、最も
気づかれにくい。出たら必ず対処する。
