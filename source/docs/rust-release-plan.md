# リリース計画

現在は Windows x64 向けの 4.0.0-alpha.3 試験版です。Rust と PowerShell でビルド・検証します。提供機能と制限は [利用ガイド](rust-preview.md) を参照してください。

標準 ZIP には実行ファイル、スキル、ライセンスに加え、監査用のソース・テスト・検体とビルド記録を含めます。依存クレートを含むオフライン再ビルド用 ZIP は別途作成します。[監査・再検証手順](audit-testing.md)を参照してください。

## 正式公開までの受入条件

- 開発ツール未導入の Windows 環境で ZIP を展開して起動できる。
- ネットワークを無効にして CLI 起動・スキル導入・基本操作を確認する。
- 日本語・空白を含むパスと一般ユーザー権限で動作する。
- スキルの新規導入・更新と利用者による編集の保護を確認する。
- 対象 Agent の新しいセッションでスキルを利用できる。
- Excel の取り込み・成形・検証・記録・採用・編集・差分・レビュー・書き戻しを一巡する。
- 書き戻した Excel を独立した処理で再読込し、値・型と変更対象外の保持を確認する。
- 未レビュー、原本更新、競合、未解決の対応、既存出力への上書きを拒否する。
- ZIP の内容、依存、対応環境、検証結果、既知の制限を記録する。

自動試験と Agent・Excel 実機での受入結果を区別し、未実施の項目を成功扱いにしません。結果は [検証記録](verification.md)、試験方法は [検証方針](test-strategy.md) に記載します。

## 今後の対応

構造・数式・図形・画像の書き戻し、非セル情報・OCR の抽出、他文書形式、仕様書生成は未対応です。対応時には依存関係・配布条件を明示し、必要な実機試験を追加します。

正式公開時には対応 Windows バージョン、ZIP の SHA-256、変更履歴を提示します。他 OS・ARM64、MSI、パッケージマネージャー、GUI は後続の検討対象です。
