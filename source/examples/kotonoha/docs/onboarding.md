# 利用を始めるまで

各部門向け。社内ポータルの「AI基盤 / Kotonoha を使う」から書き出したもの。

## 1. 利用申請を出す

社内ワークフロー「情報システム利用申請」から出す。次を書く。

| 項目 | 書くこと |
| --- | --- |
| 用途 | 何を検索したいか（例: 保守問合せの回答支援） |
| 対象の文書 | 何を入れるか。**機密区分もここで決まる** |
| 想定の件数 | 月あたりの取り込み件数。上限の根拠になる |
| 原価センタ | 費用の付け替え先 |

**機密区分は情報区分規程に従う。** 迷ったら情報セキュリティ部へ。
極秘（30）を選ぶと社内 GPU の経路になり、精度が落ちる代わりに
外部へデータが出ない。

承認が下りると AI基盤グループがテナントを作り、API キーを渡す。
**平文のキーは発行時に一度しか出ない。** 社内の秘密情報管理の規程に
従って保管すること。

## 2. コレクションを作る

```sh
curl -s -X POST "$BASE/v1/collections" \
  -H "Authorization: Bearer $KEY" -H 'Content-Type: application/json' \
  -d '{"name": "maintenance-manual"}'
```

機密区分と埋め込みモデルはテナントから継承される。
**モデルは作成時に固定で、後から変えられない**（変えるには再インデックス
が要るので運用へ依頼）。

## 3. 文書を入れる

```sh
curl -s -X POST "$BASE/v1/collections/$CID/documents" \
  -H "Authorization: Bearer $KEY" -H 'Content-Type: application/json' \
  -d '{"documents": [
        {"external_id": "MAN-A2210-01",
         "title": "A-2210 型 保守手順",
         "content_type": "text/markdown",
         "content": "# 保守手順\n\n...",
         "metadata": {"製品": "A-2210", "年度": "2026"}}
      ]}'
```

- **1 回に 1,000 件まで。** まとめて投げること（1 件ずつだとレート制限に当たる）
- 202 が返る。**まだ入っていない。** `Location` のジョブを引いて進捗を見る
- 同じ `external_id` で本文が同じものは飛ばされる（費用が掛からない）

### メタデータの付け方

検索の絞り込みに使う。**鍵は基盤側で正規化しない**ので、部門の中で
揃えておくこと。「部署」と「部門」は別物として扱われる。

## 4. 検索する

```sh
curl -s -X POST "$BASE/v1/collections/$CID/search" \
  -H "Authorization: Bearer $KEY" -H 'Content-Type: application/json' \
  -d '{"query": "異音がするときの対処", "top_k": 5}'
```

- 型番や品番は引用符で囲むと完全一致になる（`"A-2210"`）
- `filters` でメタデータを絞れる
- `explain: true` で点数の内訳が出る（当たらない原因を調べるとき）

**検索は月間上限に掛からない。** 取り込みだけが上限の対象。

## 5. 使用量を見る

```sh
curl -s "$BASE/v1/usage" -H "Authorization: Bearer $KEY"
```

上限の 8 割を超えると `warning` が立つ。超えると取り込みが 429 で
断られる（**検索は止まらない**）。

**金額は返らない。** 締めたあとの確定値は AI基盤グループへ問い合わせ。

## よくある質問

**回答文までもらえますか**
: いいえ。Kotonoha は検索までで、回答の生成は各部門で行っていただいて
  います。（※ この線引きについては調整中です）

**取り込んだのに検索に出ません**
: ジョブの進捗を確認してください。`skipped` になっていないか、
  `failures` に入っていないかを見ます。スキャンした紙の PDF は
  取り込めません（OCR 未対応）。

**請求が想定より少ないのですが**
: 同じ本文を再度入れた分と、他の文書と同じ内容の断片は、費用が
  発生していないため課金していません。
