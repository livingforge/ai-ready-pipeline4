# 販売管理の文書・コード見本

このディレクトリには、文書取り込みを試すための原本と生成用コードがあります。
`python examples/sales-corpus/build.py --help` で生成先を確認できます。

ARPへ取り込む場合は原本を利用先プロジェクト内へ置き、1ファイルずつ
`arp4 documents import <原本> --id <文書ID> --root <project>` を実行します。
候補の本文・出典を成形し、検証とレビューを経て採用してください。
文書IDはファイルごとに異なる値を使います。

操作は [文書管理の手順](../../docs/documents.md) を参照してください。
