# Excelの書式・シート・セルの操作

Excelの書式、図形の配置、シート、行の並べ替え、セル範囲のコピーと挿入削除、リンク・メモ・入力規則・条件付き書式。行・列の追加削除、`--id`・`--dry-run`・`--base`、操作の取り消しは [行・列の追加・削除と操作の取り消し](layout-edits.md)。

- Excelの書式は `documents format <文書ID> --sheet <シート> --range <範囲> --reason <理由>` で変える（候補は `--proposal`）。`--from <セル>` はそのセルの書式（罫線・塗り・表示形式・フォント・配置）を範囲に写し、挿入した行・列や追加したセルを周りと揃えるのに使う。`--wrap true|false`・`--shrink`・`--horizontal`・`--vertical` は配置だけを、`--bold`・`--italic`・`--strike`・`--underline` はフォントの強調だけを、`--fill <RRGGBB>|none` は塗りつぶしを、`--number-format <書式記号>` は表示形式を、`--border <辺>:<線>[:<色>]`（`outline:thin`、`inside:thin`、`bottom:double:FF0000`、`all:none` など。繰り返し指定可）は罫線を変え、`--row-height <ポイント>|auto`・`--column-width <文字数>` は行の高さ・列幅を、`--merge`・`--unmerge` は結合を変える（値のあるセルを隠す結合は拒否される）。範囲は、それまでに記録した行・列の操作の後の番地で指定する（`layout_warnings` の `cell` と同じ）。値は変わらない。書式を変えた行の後に挿入した行（列・セルも同様）は変えた書式と行の高さを受け継ぐので、書式元の行を先に整えてから行を足せばよい。
- Excelの図形・画像・グループの位置と大きさは `documents drawings place <文書ID> --sheet <シート> --drawing <抽出のdrawingsのID> --from <セル> --to <セル> --reason <理由>`、行・列の操作での動き方は `--placement twoCell|oneCell|absolute` で変える。図形・画像・グループにかかる行・列を挿入・削除するときは、先に `--placement oneCell` にすると伸び縮みしない。グループの中の図形はグループのIDを指定する。応答の `joined_connectors` は動かした図形に接続した線で、線は動かないので必要なら同じコマンドで動かす。セルに合わせて移動とサイズ変更をする図形・画像・グループ・線は、削除する行・列の範囲に収まるとExcelと同じく一緒に削除され、本文から文字も消える（取り消せば戻る）。一緒に削除される図形の配置は拒否される。配置の後の行・列の削除は、配置した位置で一緒に削除するかが決まる（削除する範囲の外へ配置した図形は残る）。
- Excelのワークシートを足すときは `documents sheets add <文書ID> --name <シート名> [--after|--before <シート>] --reason <理由>`、複製するときは `documents sheets copy <文書ID> --sheet <原本のシート> --name <シート名> ...` を使う（Excelの「移動またはコピー」と同じく、書式・結合・規則・リンク・メモ・図形・グラフ・印刷設定ごと写り、複製元を指す数式・グラフの系列・名前はコピーを指す。テーブルは新しい名前になる。複製元に記録した書式などの操作はコピーにも記録される）。追加したシートの値・行・書式などは、ほかのシートと同じコマンドで `sheet`・`--sheet` に新しいシート名を指定して変える。行・列・セルの挿入削除を記録したシートは複製元にできないので、先に複製する。ピボットテーブルのあるシートはExcelで複製する。原本のシートの削除は `documents sheets delete <文書ID> --sheet <シート> --reason <理由>`、名前の変更は `documents sheets rename <文書ID> --sheet <シート> --name <新しい名前> --reason <理由>`（Excelと同じく、指していた数式・名前は `#REF!` になる、または新しい名前を指す）。どちらもexportの最後に行うので、ほかのコマンドではシートを原本の名前で指し、空いた名前はexportまで使えない。削除するシートに記録した操作と値の編集は除かれる。
- Excelの行を並べ替えるときは `documents rows move <文書ID> --sheet <シート> --from <行> [--count <行数>] --after|--before <行> --reason <理由>` を使う（行番号は原本の番号。Excelの切り取りと挿入と同じく、値・数式・書式・高さ・結合・リンク・メモ・入力規則・行に収まる図形が移動先へ動き、移動する行を読む数式はExcelと同じ式に書き直される）。名前定義が移動する行の端を指す、入力規則・条件付き書式が移動する行と移動先の片方だけにかかる、図形が移動する行の外にまたがる、移動する行に記録済みのコピー・画像の操作がある場合は `structural_edit_unsupported` で拒否されるので、Excelで移動するか、移動の後に記録する。
- Excelのセル範囲を同じシートの別の場所へ写すときは `documents cells copy <文書ID> --sheet <シート> --range <範囲> --to <写し先の左上> --reason <理由>` を使う（Excelの貼り付けと同じく、値・相対参照をずらした数式・書式・結合・リンク・メモ・入力規則・条件付き書式が写る。`--values-only`・`--formats-only` で絞れる）。写し先の値のあるセルへの数式、数式のあるセルへの値は拒否されるので、先に `documents values` で空にする。範囲は `format` と同じく、それまでに記録した行・列の操作の後の番地。記録の形をまとめて増やすときは、先に `rows insert` で行を空けてからコピーする。
- Excelのセルのリンクは `documents links set|clear`（`--location <シート!セル>` か `--url`）、メモは `documents notes set --cell <セル> --text <文字>`・`notes clear`、入力規則は `documents validations set`（`--list a,b`・`--source <=範囲>`・`--type whole|decimal|date|time|text-length --operator <比較> --value1 [--value2]`・`--formula`）・`validations clear`、条件付き書式は `documents conditional-formats add`（`--formula <=数式>` か `--cell-is <比較> --value1`、書式は `--fill`・`--font-color`・`--bold` など）・`conditional-formats clear` で変える（候補は `--proposal`）。範囲は `format` と同じく、それまでに記録した行・列の操作の後の番地。既存のものは `documents extraction-read` のシートの `links`・`validations`・`conditional_formats`・`comments` で読む。本文の値は変わらない。
- Excelのセルを挿入・削除して周りのセルをずらすときは `documents cells insert <文書ID> --sheet <シート> --range <範囲> --shift down|right --reason <理由>`、`documents cells delete <文書ID> --sheet <シート> --range <範囲> --shift up|left --reason <理由>` を使う（候補は `--proposal`、`--id`・`--base`・`--dry-run`・`--vba-unchanged` は行の操作と同じ）。Excelの「セルの挿入」「削除」と同じく、範囲の列の中（下・上）か行の中（右・左）だけでセルが動き、数式・結合・テーブル・条件付き書式・入力規則・図形もExcelと同じに追従する。本文の値はすぐにずれた先に表示され、挿入したセルは空で、その位置の要素ID（`cell_r5_C` など）を `documents values` の `element` に指定して値を入れる。削除したセルの値は本文から除かれ、応答の `deleted` に並ぶ。範囲はそれまでに記録した行・列の操作の後の番地。テーブル・配列数式・結合の一部だけにかかる範囲は `writeback_refused` で拒否されるので、範囲を広げるか先に `documents format --unmerge` で結合を解除する。表の途中でセルをずらすと表の記録の行がそろわなくなるので、記録を足す・消すときは `documents rows` を使う。
