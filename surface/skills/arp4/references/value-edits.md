# 値・数式・フォントの編集

候補と採用済み文書の既存内容を `documents values` で変える。構造と書式は [行・列](layout-edits.md)、[Excelの書式・シート・セル](excel-edits.md)、[PowerPointのスライドと図形](slide-edits.md) の操作、原本への反映は [原本への反映](writeback.md)。

- 成形はimportのJSONにある `document_id` の候補に対してCLIで行う。値・数式・フォントの変更と空のセルへの入力は `documents values --proposal <文書ID> --input <編集JSON>`（この資料の「既存内容の編集」）、行・列・スライド・図形は専用コマンド（[行・列](layout-edits.md)、[Excelの書式・シート・セル](excel-edits.md)、[PowerPointのスライドと図形](slide-edits.md) の操作）に `--proposal <文書ID>` を付ける。本文YAML・`mappings.yml`・`layout.yml` は直接編集しない（手で編集した本文は書いた文字と読み取られる値が異なる書き方や木の変更をcheckが拒否する）。
  WordとPPTXは段落内の改行・タブを編集できる。PDFは改行・タブを置換文字列に含めず、既存の文字列を個別に編集する。
- 既存内容の編集は `documents values <文書ID> --input <編集JSON> [--dry-run]`（候補は `--proposal <文書ID>`）を使う。入力は `documents schema value-edits` の契約に従い、`documents check <文書ID> --include-hashes` の `content` を `base`、`source_sha256` を `source_sha256` に入れ、各editに期待する旧値 `before` を書く（値のないセルは `null`）。原本で空のセルや挿入した行のセルに入れた値は、`after: null` で空に戻すと本文からも除かれる。対象は `cell`（`documents extraction-read` の出力にある原本の番地）、`shape`（Excelの図形の抽出ID）、`element`（`documents elements-read` の出力の `element_metadata` の要素ID）のいずれかで指定し、`sheet` にシート名・ページ名を書く。挿入した行・複製したスライドの値は `element`（`cell_<操作ID>-1_C` など）で指定する。Excelでは原本で空のセル（表の空欄、挿入した行の未入力のセル）にも、同じ規則の番地・要素IDで値を入れられ、表の範囲の内側なら表の記録に入る（シートの行・列の範囲外、結合の左上以外は拒否）。全変更を未適用の操作とともに文書形式ごとの書き戻し処理で事前検証し、1件でも不正なら保存しない。要求のactor・reason・editsは `mappings.yml` の `value_edits` に記録され、exportのreportにも載る。管理YAMLを直接編集しない。既存数式のbefore・afterには `=` 付きの数式原文を指定し、文字列セルの `=` は文字列のまま扱う。読み取り専用のフィールド、結合の非アンカー、型の異なる値は拒否する。Excelでrunをまたぐrich text変更は拒否するため、必要ならExcelで編集して再importする。ふりがな（読み）のある文字列は編集でき、変更しなかった部分の読みは保たれ、変更した部分にかかる読みは失われる（読みが必要ならExcelで入力し直す）。同じ文字列が繰り返され変更箇所が一意に決まらない編集は拒否する。Word・PowerPointは段落内の改行・タブの変更に対応し、PDFは元フォントで表せない文字や改行・タブを拒否する。Excelでは応答の `layout_warnings` に、セル・図形の大きさとフォントから文字が収まらない見込みの編集を返す（`clipped`: 切れる、`row_grows`: 行が高くなる、`line_breaks_hidden`: 折り返しのないセルで改行が表示されない、`overflows_shape`: 図形からあふれる）。長い文を書くときは先に `--dry-run` で確かめ、警告があれば文を短くするか、`documents format` で行の高さ・列幅・折り返しを変える（図形の大きさはCLIで変えられないので利用者に依頼する）。警告がなくても見込みであり、任意長の文章と固定レイアウトの両立は保証しないので、出力を描画して確かめる。対応形式・対象の一覧は生成された機能・契約リファレンスを参照する。
  - 拒否は `error.code` で判断し、`error.edit`（要求の `edits` の添字）と `error.target` で対象を特定する。`invalid_request`、`invalid_document`、`base_changed`（版が変わった。checkを読み直す）、`source_changed`、`unsupported_format`、`sheet_not_found`（`error.sheets`）、`target_not_found`、`not_editable`（書き戻し対象外。理由はmessage）、`duplicate_target`、`before_mismatch`（`error.current` に現在値。`cell` は原本の番地で、未適用の行・列・セルの操作で位置が変わるシートでは `error.moved` に原本のセルが今ある番地 `shown_at` と、指定した番地に今あるもの `address_shows` が返る。exportや `format`・`cells` の番地と取り違えていないか確かめ、原本の番地か `element` で指定し直す）、`value_type_mismatch`、`font_unsupported`（挿入した行・スライドや非対応形式のフォント）、`validation_failed`、`writeback_refused`（原本の書き戻し処理が拒否。32件以内の要求では単独でも拒否されるeditの添字を `error.edits` に返す）。
  - 同じ値を指定し直した要求は `unchanged` になり、記録も増えない。
- フォント名・サイズ・色は、原本の値を `documents extraction-read` の出力のセルの `font`（持たないセルはそのシートの `cell_font`。`null` はフォントなし）と図形の `font`、現在値を `documents elements-read` の出力の `element_metadata` の `font`（持たない要素・セルはそのページの `element_font`。`null` はフォントなし）で読む。スタイル・テーマの継承を解決した表示上の値で、要素内のrunで異なる項目は `mixed` で、各runがその文字（`start` から `end` の手前まで、文字列の先頭からの文字数）に示す値を `runs` に持ち、解決できない項目は `null`。変更は `documents values` のeditに `font: {before, after}` を書く（`after` は変える項目だけ、`before` は同じ項目の現在値）。値の変更と同じeditにまとめられる。現在の対象はExcelのセルと図形の文字（`cell` の代わりに `shape` へ図形の抽出IDを指定）とWord・PowerPointの段落・表のセルで、Excelのセルはフォント名が1つなので `latin` と `east_asian` に同じ名前を指定する。Wordのサイズは0.5ポイント単位、PowerPointの色は `RRGGBB` だけ（`auto` は不可）。PDFのフォントは読み取りのみ。色を指定するとテーマ色の参照は外れる。`layout.yml` を直接編集しない。
- 文字列の先頭が `=` でも数式化しない。既存の数式は、表の外では本文要素 `formula`、表では列見出しのキーの値にある数式原文（`=` から始まるファイル内の表記。新しい関数は `_xlfn.` 付き）を同じ位置で編集すると置き換わり、行・列操作では参照が移動する。スピルする関数・`LET`・`LAMBDA`・`#`・`@` と値セルの数式化はExcelで行う。原本で空のセル・挿入した行のセルには、`documents values` のeditに `"formula": true` を付けて `after` に数式（原本の位置で書く）を入れるか、`rows insert --values` で `{A: {formula: "=ROW()-4"}}` のように渡す（`=` で始まる文字列そのままは文字列になる）。Excelテーブルの見出しセルの編集は列名の変更になり、ブック内の構造化参照も書き換わる（空・重複・改行を含む列名は拒否）。集計行のラベルも編集できる。図形の文字は参照要素 `drawing: null` に続く本文の `text`、または `diagram` の図形・線の `text`、`checkbox` の `text` を改行の数を変えずに編集する。`diagram` の図形の種類・位置・線、`checkbox` の状態・リンク先・位置は原本から決まり、変更は拒否される（チェックボックスの状態はリンク先セルの値で変える）。図形の追加・削除・移動、画像の回転・トリミング・絶対座標は拒否される。画像は `documents images add` の `--from` / `--to` のセルで配置する。構造変更時は全シートの数式参照・名前定義・テーブル・条件付き書式・入力規則・結合・既存Drawingのセルアンカーを移動し、Excelで再計算する。移動した数式の計算結果は空になり、Excelで開くと再計算される。
- 型や構造の変更が必要なら未対応と報告し、検証を回避しない。
